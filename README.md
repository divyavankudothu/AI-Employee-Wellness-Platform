# AI-Based Employee Wellness Management Platform

An AI-powered employee wellness management platform that analyzes
employee feedback using Natural Language Processing and sentiment
analysis.

## Milestone 1 — Text Ingestion & Baseline Sentiment

Milestone 1 focuses on building and validating the foundational
text processing and baseline sentiment analysis pipeline.

### Features

- Manual text input
- TXT file ingestion
- CSV file ingestion
- Input validation
- Empty and invalid input handling
- Text preprocessing
- Tokenization
- Stop-word removal
- Lemmatization
- Noise filtering
- Special character and punctuation handling
- VADER sentiment analysis
- Positive sentiment detection
- Negative sentiment detection
- Neutral sentiment detection
- Sentiment score generation
- Initial sentiment report
- End-to-end pipeline testing

## Technology Stack

- Python
- Pandas
- NumPy
- NLTK
- VADER Sentiment
- Google Colab
- GitHub
